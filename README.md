# VELVET DUCK // XCHAIN LAB

**OoakosiMo's Imaginary Secretary: Velvet Duck**

She's Ducky & Dangerous.  
A Quack to Kill For.  
When Feathers Fly, Heads Will Roll.

This repository is a small experimental lab for testing how browser-native and image-based artworks can move through the XChain ecosystem.

Velvet Duck is OOAKOSIMO's imaginary secretary: equal parts femme fatale, surreal office phantom, cyberpunk gangland operator, administrative enforcer, and complaint-processing menace.

## Why this repo exists

This lab is being used to test:

- XChain token metadata
- token thumbnails / icons
- externally hosted images
- JSON metadata
- interactive HTML
- XChain `FILE` actions
- on-chain media references
- `data_ref: action:<index>`
- testnet rendering behavior
- future contract-driven artwork experiments
